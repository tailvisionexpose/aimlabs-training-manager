## About

Aimlabs Training Manager helps FPS players organize their aim training routines. Track playlist progress, log scenario scores over time and plan structured training programs to improve specific aim mechanics.

---

## Features

| Feature | Description |
|---------|-------------|
| **Training Planner** | Build structured aim training playlists by skill category |
| **Score Tracker** | Log daily scores per scenario to track improvement over time |
| **Weakness Analysis** | Identify which aim mechanics need the most focused practice |
| **Routine Builder** | Plan weekly training schedules with time and scenario targets |
